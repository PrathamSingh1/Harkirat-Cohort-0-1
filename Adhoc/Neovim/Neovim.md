1. Open Sidebar -

space + e - open the sidebar
arrow up,down - move between files
enter - opne that file
r - rename that file
d - delete that file

2. Find A File -

space + ff - find file search bar
esc + esc - to exit of the find file search menu

3. File Navigation -

gg - to reach the top of the file
G - to reach the bottom of the file
0 - start of the line
$ - end of the line
e - fast forward
b - fast backward

4. Search Across Codebase -

space + sg

5. Find and Replace -

: - it will open the Cmdline
%s/ToReplace/Replace/g - it will replace that

6. Splitting Windows -

space + | - split horizontally
space + - - split vertically
:q! - to exit the current window
ctrl + H/J/K/L - navigate windows

7. LSP -

gd - go to definitions
Autocomplete
shift + k - hover documentation
space + cr - smart replace
space + cf - format the code
space + ca - code actions
space + cr - removed unused imports
space + co - organize imports

8. Switch Buffers -

[ + b - go to the left
] + b - go to the right

9. Line Numbers

linenumber + j - to go down to that number
linenumber + k - to go up to that number
space + ul - disable/enable line numbers

10. Open Terminal -

space + ft - open terminal
exit - to exit out of terminal

11. Explore -

: - to go to the Commandline
Explore - go to the file system where you want to make file or folder
% - add a file
d - add a folder

12. Visual mode - v

u - undo
ctrl + r - redo
y - for yanking or copying
dd - cut the line
p - paste
v + i then " or ( whatever the starting and ending point between you want to copy
