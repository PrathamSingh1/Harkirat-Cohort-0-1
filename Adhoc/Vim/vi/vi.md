vi is a terminal based editor

-> Projects vi index.ts

Normal mode - initally you will be in normal mode but when you go to Insert mode then by pressing esc you can come back to normal mode.

1. h -> left, l -> right, j -> down, k -> up
2. 0, $
3. e, b
4. gg, G
5. p -> paste

Visual mode - for selecting the text you can exit is by pressing esc.

1. h -> left, l -> right, j -> down, k -> up
2. 0, $
3. e, b
4. gg, G
5. y -> copy
6. d -> cut
7. dd -> delete the line

Insert mode - by pressing i you can enter insert mode.

Type something!

Extra commands -

1. Exiting out of vi

a. :q - without saving anything
b. :q! - don't save and exit
c. :w - saving your file without exiting it
d. :wq - saving and exiting

2. Undo redo

a. u -> undo
b. ctrl + r -> redo

3. Search

a. /+ what_to_search
b. :line_number -> go to line
